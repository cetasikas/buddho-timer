## ✨ Core Features

* 🔔 **Authentic Acoustic Chimes**: High-fidelity recordings of mindfulness bells, deep monastery bells, and Tibetan singing bowls with natural reverberation.
* 🫁 **Mindful Box Breathing**: Built-in Pranayama pacing (*Inhale, Hold, Exhale, Hold*) with rhythmic visual cues and configurable intervals.
* 📳 **Silent Haptics**: Multi-stage tactile vibration waveforms for quiet meditation in shared or silent retreat settings.
* 🌑 **Distraction-Free Interface**: Deep obsidian dark mode for zero eye strain, gentle falling leaf animations, and tap-to-blackout display.
* 📊 **Practice Journal & Streaks**: Track your daily practice consistency and meditation milestones in a local SQLite database.
* 🔒 **100% Offline & Private**: Zero user tracking, zero advertisements, no user accounts, and no network permissions (`android.permission.INTERNET` is completely absent).
* 💾 **Data Sovereignty**: Manual JSON/CSV backup export and automatic Google Drive sandbox backup support.

* **Zero Monetization**: Free and open to all practitioners.
